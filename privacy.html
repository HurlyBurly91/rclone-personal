Privacy Policy

This application is a private, personal-use integration for the repository owner and is used with rclone to access the owner's own Google Drive accounts.

Google user data accessed

The application may access Google Drive files, folders, file metadata, and related information that the authenticated account owner explicitly authorizes through Google OAuth.

How data is used

Google user data is used only to perform file operations requested by the account owner, including synchronization, backup, copying, listing, and filesystem access through rclone.

Data storage

OAuth credentials and rclone configuration are stored locally on systems controlled by the account owner. Google Drive file data may also be stored locally when the account owner explicitly copies, synchronizes, caches, or backs up files.

Data sharing

This application does not sell Google user data. It does not disclose Google user data to third parties except when the account owner explicitly directs a file operation or when required by law.

Data retention and deletion

Locally stored files and credentials remain under the control of the account owner and may be removed by the owner at any time. Google OAuth access may also be revoked through the Google account's security settings.

Scope

This site documents a personal rclone integration and is not a public software-as-a-service product.
