# rclone-personal

Public informational pages for a private, personal-use rclone Google Drive OAuth client.

This repository contains no OAuth client secret, refresh token, rclone configuration, or Google Drive data.

## GitHub Pages

Publish the repository from the `main` branch and `/ (root)`.

Expected URLs after GitHub Pages is enabled:

- Home: https://hurlyburly91.github.io/rclone-personal/
- Privacy policy: https://hurlyburly91.github.io/rclone-personal/privacy.html

These URLs can then be used on the Google Auth Platform Branding page before changing the OAuth app from Testing to In production.
